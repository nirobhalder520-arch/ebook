# BoiMarket - Professional Ebook Selling Platform

A complete, production-ready ebook marketplace platform built with modern web technologies.

## Project Overview

BoiMarket is a professional ebook selling platform similar to Boighor, featuring:
- Responsive modern UI with Bootstrap 5
- Secure user authentication system
- Complete book management system
- Shopping cart and checkout with multiple payment gateways
- Admin dashboard with analytics
- PDF protection and watermarking
- Advanced search and filtering
- User dashboard with order and library management

## Tech Stack

- **Frontend**: HTML5, CSS3, Vanilla JavaScript, Bootstrap 5
- **Backend**: PHP 8+
- **Database**: MySQL
- **Server**: Apache/Nginx with PHP

## Features

### Public Website
- 15+ fully responsive pages
- Modern hero banner with slider
- Featured books, bestsellers, new arrivals
- Advanced search with filters
- User authentication system
- Shopping cart and checkout

### User Dashboard
- Profile management
- Order history
- Digital library with reading capability
- Wishlist management
- Download history
- Reviews and ratings

### Admin Panel
- Dashboard analytics
- User, author, publisher management
- Book management with PDF upload
- Category management
- Order management
- Coupon system
- Payment management

### Security
- SQL injection protection
- XSS prevention
- CSRF tokens
- Secure session management
- Password hashing (bcrypt)
- PDF watermarking and download limits
- Secure download endpoints

### Payment Integration
- bKash
- Nagad
- Rocket
- SSLCommerz
- Stripe
